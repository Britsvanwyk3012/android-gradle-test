## TEST 13 implementation completed
1. Edit CANCEL is now SUPER UNDO: restores the state from when Edit was opened, stays on the Edit page, and never deletes the saved client.
2. Edit RETURN is now a navigation action. If unsaved edits exist, it asks: “Leaving this page before saving will lose all edits, Are you sure?” NO / STAY keeps the edits; YES / LEAVE discards them and returns to Main Capture.
3. Edit SAVE has its own path: save locally, verify the saved record, rebuild Main Capture, and restore the complete saved client information.
4. Telephone paste is handled by the focused telephone field only; it cannot write into or replace another telephone field.
5. Existing TEST 12 Google/custom-label, exact phone-list sync, deletion sync, and NEW NUMBER DETECTED workflow are preserved.
6. Existing UNDO behaviour is preserved.
7. App versionName corrected to 12.04; versionCode advanced to 125.
